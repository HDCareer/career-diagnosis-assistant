# SkillⅠ｜会前材料归一化规范

## 1. 可接受的顾问输入

允许顾问直接提供完整简历、运营同事的自然语言摘要、客户聊天记录摘录、5 个固定问题的编号回答、表格、Markdown、普通文本、多版本完整简历或“无额外补充”。不得要求顾问必须填写 YAML 或标准字段表。

## 2. 内部归一化目标

以下结构只供后续工作流使用，不直接展示给顾问：

```yaml
resume_status:
fixed_questions:
  target_region_and_city:
  role_preferences_and_exclusions:
  graduation_and_start_date:
  salary_expectation:
  expected_questions_to_solve:
region_specific_answer:
operating_notes:
  resume_versions_provided:
  explicit_deadlines:
  confirmed_material_gaps:
  customer_stated_focus:
  other_decision_relevant_notes:
unresolved_items:
  - question:
    source_reference:
    why_decision_relevant:
    unresolved_reason_type: explicit_missing | conflict | required_qualification | region_required
conflicts:
```

## 3. 会前门槛与提取规则

会前初版仍须满足冻结核心的完整简历、5 个固定问题、1 个地区动态问题和运营补充信息存在性门槛。5 个问题为：

1. 主要求职地区及明确城市。
2. 想做或明确不想做的行业、岗位。
3. 毕业时间和最早全职到岗时间。
4. 薪资目标、币种及月薪或年薪口径。
5. 报告和咨询最希望解决的问题。

地区动态问题按中国内地、香港、澳洲、美国或多路径中已确认的目标地区选择一个。无法判断地区时，先只补问地区，不预设问题类型。

从简历优先提取学校、学历、专业、毕业时间、实习和工作经历、项目、技能、语言、证书、明确城市或岗位信息、时间线和多版本差异。简历中未出现的内容只能标记为“当前材料未见”，不得判断为事实不存在。

## 4. 自然语言摘要处理

顾问自然语言中出现的地区、城市、岗位偏好、主动排除、薪资未知和咨询诉求，应自动归入对应会前信息及运营补充信息。例如“想留上海，运营和市场都可以看看，不接受销售，薪资还没想好，最关心自己适合什么”，应提取为城市偏好、岗位偏好、主动排除、有效薪资未知和咨询诉求；不得要求顾问重新填写表格。

## 5. 有效未知

“不知道”“不清楚”“还没想好”“希望顾问建议”“没有明确要求”均是有效未知。有效未知不阻塞会前报告，但必须进入待确认事项和咨询重点，不能被自动补成明确答案。

每个 `unresolved_items` 必须保留结构化来源：`source_reference`、`why_decision_relevant` 和 `unresolved_reason_type`。允许来源类型仅为：

- `explicit_missing`：输入明确提出但尚未回答，或已明确指出材料/口径缺失。
- `conflict`：已知事实之间存在冲突。
- `required_qualification`：当前方向成立所必需的资格、身份、工作权利或时间条件。
- `region_required`：地区规范明确要求核查的项目。

平台规模偏好不得自动扩展为行业偏好补问；客户未提出的家庭、预算、语言、行业、性格或生活偏好不得自行进入待确认事项，除非属于路径硬性条件或地区规范必查项。仅仅“有助于进一步了解客户”不能构成决策必要性。

当 `operating_notes.explicit_deadlines` 中存在早于报告日期后 30 天的明确截止日，归一化结果必须把该日期保留为第一阶段优先约束；后续报告不得再把同一事项写成“30天内完成决策”。

## 6. 冲突识别

仅学历、学校、专业、毕业时间、公司、岗位、经历时间线、目标地区、到岗时间、明确岗位排除和薪资口径的重大冲突需要确认。多版本简历的排序、标题和重点差异通常不视为冲突。
