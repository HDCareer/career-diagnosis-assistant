# SkillⅠ｜差量补问规范

## 1. 基本原则

```text
先读取已有材料
→ 标记已确认
→ 标记有效未知
→ 标记缺失
→ 标记冲突
→ 只询问缺失和必须解决的冲突
```

补问只用于满足冻结核心的会前输入门槛或解决重大事实冲突。

所有待补问或待确认事项必须能落到结构化来源集合：`source_reference`、`why_decision_relevant` 和 `unresolved_reason_type` 均不可缺失。`unresolved_reason_type` 只允许 `explicit_missing`、`conflict`、`required_qualification`、`region_required`。

## 2. 不应补问

以下情况不得重复询问：

1. 简历已经明确毕业时间。
2. 运营摘要已经明确目标城市。
3. 客户已经明确说不知道薪资。
4. 客户已经明确排除销售岗位。
5. 已经提供有效的地区动态问题答案。
6. 运营补充已明确为“无额外补充”。
7. 仅从“成熟科技公司”“中型互联网公司”“业务稳定平台”等平台规模偏好推导出的行业偏好补问。
8. 客户未提出、也非路径硬性条件的家庭、预算、语言、行业、性格或生活偏好。

## 3. 必须补问

只有以下情况补问：

1. 没有完整简历。
2. 某个固定问题完全没有答案。
3. 地区动态问题完全没有答案。
4. 运营补充是否遗漏无法判断。
5. 重大事实存在互相冲突的版本。
6. 无法判断目标地区，因而无法确定地区动态问题。
7. 当前路径成立所必需的资格、身份、工作权利或时间条件缺失。
8. 输入已明确指出成果数字、材料佐证或计算口径缺失，且该缺口会影响方向判断、简历表达或行动安排。

## 4. 问题表达与数量

每题只问一件事，使用顾问能理解的中文，允许回答“不知道”，不使用内部字段名，不带销售诱导，也不暗示必须购买后续服务。

每轮只列当前真正需要处理的项目：全部 5＋1 都缺失时可一次问完；只缺 2 项时只问 2 项。顾问回答后重新归一化，不再次展示已回答问题。

## 5. 冲突展示格式

```text
以下信息存在两个版本，需要确认：

1. 毕业时间
- 简历A：2026年6月
- 简历B：2026年12月

请确认最终采用哪个版本；如果暂时无法确认，可以回答“未确认”。
```
