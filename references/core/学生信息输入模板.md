# SkillⅠ v3.0｜学生信息输入模板

## 使用目标

本文件规定会前诊断初版的输入。它只收集支持求职方向判断的必要信息，不使用重型信息表，不默认询问家庭、付款、家长意见或销售相关内容。

会前材料满足条件后，只生成 `pre_consultation_report_data.json` 和 `pre_consultation_report.md`。咨询后的新增信息必须使用 `咨询纪要输入模板.md`，不能直接覆盖会前材料。

## 1. 会前诊断初版的必备输入

必须同时具备：

1. 一份完整简历。
2. 5 个固定问题的有效回答。
3. 1 个地区动态问题的回答。
4. `operating_notes` 字段（如已知的材料版本、明确时间节点或客户特别说明）。

具体岗位、薪资、城市允许回答“不知道 / 不清楚 / 还没想好”。这属于待确认边界，不阻塞会前初版，但必须进入咨询议题，不能被虚构为明确答案。

## 2. 简历处理原则

1. 简历是会前事实的主要来源；已明确的信息不重复追问。
2. 简历未出现的普通实习、项目、证书和技能，默认当前没有可作为会前判断依据的材料，不等同于事实不存在。
3. 片段、截图、局部页面或只有教育经历的材料不构成完整简历。
4. 简历量化成果可用于判断，但会前报告不得补造数据；咨询中可确认其来源、个人贡献和结果口径。
5. 多版本简历的标题、排序、重点和定向删减差异通常不视为冲突；只有时间线、学历、公司、岗位或毕业时间等重大事实冲突才标为待核实。

## 3. 五个固定问题

```text
1. 你当前主要考虑在哪里求职？是否有明确城市？

2. 你现在有没有想做或明确不想做的行业、岗位？

3. 预计毕业时间和最早全职到岗时间是什么时候？

4. 是否有明确薪资目标？请说明币种，以及是月薪还是年薪。

5. 这次报告和顾问咨询最希望解决什么问题？最多写三项。
```

## 4. 地区动态问题

按当前目标地区只追加 1 个问题：

### 中国内地

```text
是否有必须去或明确不接受的城市？是否只接受大厂、外企、央国企或其他特定公司类型？
```

### 香港

```text
当前是否持有 IANG、高才或其他可工作身份？是否会粤语？主要目标是长期留港，还是将香港作为职业经历或身份路径之一？
```

### 澳洲

```text
当前签证情况是什么？是否计划申请或已持有 485？主要目标是 PR、长期留澳，还是先积累 1—2 年海外经验？
```

### 美国

```text
当前签证及 OPT / STEM OPT 的已知状态是什么？是否接受未来可能需要 Sponsor？主要目标是长期留美、争取绿卡，还是先积累海外经验？
```

### 多路径

```text
当前本人最倾向哪条路径？最纠结的核心原因是什么？
```

## 5. 运营补充信息

`operating_notes` 字段必须存在。运营只补充已知且影响咨询准备的事实，例如：

```yaml
operating_notes:
  resume_versions_provided:
  explicit_deadlines:
  confirmed_material_gaps:
  customer_stated_focus:
  other_decision_relevant_notes:
```

运营没有额外补充时，可以填写“无额外补充”，或保留上述 5 个字段为空数组/标准空值。`operating_notes` 允许为空，但字段必须存在，不得因此阻塞会前诊断初版。只有字段完全缺失、无法判断是否遗漏材料时，才提醒运营确认。

不得把运营猜测、销售判断、家庭预算、付款人或家长态度写入该结构。

## 6. 输入状态处理

### 完整简历 + 5 个固定问题 + 地区动态问题 + `operating_notes` 字段

生成会前诊断初版，并显示“会前诊断初版｜供1v1咨询讨论使用”。`operating_notes` 可为空；初版要列出咨询中需要确认的问题，但不生成最终行动清单。

### 只有完整简历

不生成会前初版。先补充 5 个固定问题、地区动态问题和运营补充信息。

### 只有聊天记录、轻量信息表或一句话背景

不生成会前初版或最终报告。只输出已知信息、缺失材料、完整简历请求、5 个固定问题、地区动态问题及最多 2—3 个低置信度宽泛方向启发。

### 只有简历截图、局部页面或残缺材料

必须说明：

> 当前材料为简历片段 / 截图，未确认是否为完整简历，因此不能生成会前诊断初版或咨询后最终报告。请先补充完整简历。

不得把截图未出现的内容判断为不存在；可写“当前截图未见正式实习”，不得写“你没有正式实习”。

## 7. 家庭信息边界

默认不问家庭是否参与决策、谁付款、是否需要三方会议、家长可能反对点或家庭预算。只有主动提供、且直接影响地区、城市、身份路径或岗位选择的明确硬性要求，才能作为求职边界客观记录。

如用户另行要求销售准备、家长沟通或三方会议设计，应交给 SkillⅡ；SkillⅠ 不默认生成。
