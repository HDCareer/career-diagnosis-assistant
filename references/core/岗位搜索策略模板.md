# SkillⅠ v3.0｜岗位搜索策略模板

## 使用目标

本模板只用于用户显式调用的「轻量市场校准」，属于未来可选增强能力，不是 SkillⅠ v3.0 的默认主流程，也不是 正式诊断报告的必做步骤。

默认模式不读取、不调用本文件，不要求联网搜索、不要求登录 BOSS / LinkedIn / 招聘平台、不要求岗位级证据闭环、不输出具体投递清单。

本模板不影响正式报告是否可以生成，SkillⅠ 不应在默认报告中自动建议启动市场校准。

只有用户明确提出以下类似指令时，才启用本模板：

1. 启动市场校准。
2. 用岗位样本校准。
3. 搜索市场岗位。
4. 分析这几条 JD。
5. 使用《岗位搜索策略模板》。
6. 使用《岗位证据记录模板》。

## 1. 什么时候使用本模板

用户显式调用市场校准后，可用以下情况判断校准重点：

1. 学生目标薪资明显偏高，需要验证可行性。
2. 学生目标城市限制很强。
3. 学生目标岗位很窄。
4. 学生专业小众，常规回国路径不清晰。
5. 顾问对某方向判断信心不足。
6. 用户明确要求市场依据。
7. 用户明确要求验证某方向、薪资或城市可行性。
8. 用户提供岗位样本并要求分析。

轻量市场校准只回答方向级问题，不做岗位投递计划。

## 2. 校准问题清单

每次轻量市场校准只回答：

1. 这个方向市场上是否常见。
2. 这个方向大概看什么能力。
3. 这个方向和学生背景是否大致匹配。
4. 这个薪资目标是否大致合理。
5. 是否需要渠道进一步确认。

不回答：

1. 学生具体投哪 20 个岗位。
2. 哪家公司一定适合。
3. 哪个岗位一定能投。
4. 哪个岗位一定有机会。
5. 具体投递节奏和网申安排。

## 3. 可用信息来源

可以使用：

1. Google / 搜索引擎公开搜索。
2. 企业官网。
3. 校招官网。
4. 牛客。
5. 国聘。
6. 应届生求职网。
7. 公众号公开招聘。
8. BOSS / 猎聘 / 智联 / 前程无忧等招聘平台公开信息。
9. 用户人工提供的 3-5 条岗位样本。
10. 顾问已有渠道反馈。

海外本地求职可额外使用：

1. 官方政策页面。
2. 企业官网。
3. Graduate Program 页面。
4. 公司 Career 页面。
5. 学校 Career Center。
6. GradConnection / Prosple / SEEK / Indeed 等公开页面。
7. 顾问人工提供的 3-5 条岗位样本。

不默认使用：

1. LinkedIn 自动抓取。
2. 需要登录的平台。
3. 无法稳定访问的平台。
4. 自动批量爬虫。

如果 Codex 当前环境不能联网，直接输出人工搜索建议，不要编造市场结论。

## 3.1 海外轻量市场校准问题清单

海外本地求职校准只回答：

1. 这个方向在当地是否常见。
2. 是否有公开岗位样本。
3. 是否接受 international students。
4. 是否要求 full working rights。
5. 是否明确 no sponsorship。
6. 是否适合 Graduate / Entry-level。
7. 常见能力要求。
8. 薪资大致口径。
9. 学生背景是否大致匹配。
10. 是否需要进一步渠道确认。

不回答：

1. 学生具体投哪 20 个岗位。
2. 哪家公司一定适合。
3. 哪个岗位一定能投。
4. 哪个岗位一定有机会。
5. 具体投递节奏。
6. 任何 Offer、内推、录用保障。

检索结果分级：

| 分级 | 含义 | 输出方式 |
|---|---|---|
| 样本充足 | 多个公开样本支持方向级判断 | 可输出方向常见度、能力要求和薪资口径，但不输出投递清单 |
| 样本有限 | 仅少量样本支持 | 只能输出初步判断，建议继续渠道确认 |
| 样本不足 | 样本不足以支持判断 | 标注为样本不足，不得强讲 |
| 检索失败 | 无法联网、平台不可用、需登录、关键词无结果 | 输出人工搜索建议和待校准结论 |
 
检索不到岗位，不能直接等于市场没有机会。只能说明：

```text
在本次检索范围、关键词、平台和时间点下，未获得足够公开岗位样本。
```

## 6. 平台建议

| 平台 / 来源 | 适合校准什么 | 注意事项 |
|---|---|---|
| 搜索引擎 | 快速判断方向是否常见 | 结果需复核，不直接当结论 |
| 企业官网 / 校招官网 | 校招届别、岗位方向、毕业时间范围 | 以公告为准 |
| 牛客 / 应届生求职网 | 校招方向、应届岗位、讨论信息 | 注意帖子时效 |
| 国聘 / 央国企官网 | 央国企方向和招聘批次 | 需确认资格要求 |
| 公众号公开招聘 | 非标准招聘渠道补充 | 需看发布日期 |
| BOSS / 猎聘 / 智联 / 前程无忧 | 市场样本、薪资口径、岗位要求 | BOSS 不作为默认主流程 |
| 顾问人工样本 | 快速方向校准 | 每个方向 3-5 条即可 |
| Graduate Program 页面 | 海外校招 / Graduate 方向、时间线、要求 | 看是否要求 full working rights 或 no sponsorship |
| 公司 Career 页面 | 本地 entry-level / internship / contract 机会 | 不把单个岗位写成确定机会 |
| 学校 Career Center | 本地求职窗口、雇主活动、国际学生资源 | 以学校公开信息为参考，不承诺机会 |
| GradConnection / Prosple / SEEK / Indeed | 澳洲公开岗位样本 | 注意 full working rights、visa、graduate year 要求 |
| Indeed / 企业官网 / 官方 career 页面 | 美国公开岗位样本 | 注意 sponsorship、OPT、new grad、location、remote 限制 |

## 7. BOSS 人工岗位样本投喂模式

BOSS 自动检索不稳定时，优先使用人工岗位样本投喂模式。

流程：

1. 顾问自己在 BOSS / Chrome / App 中搜索。
2. 每个方向截取或复制 3-5 条岗位样本。
3. Skill 只做方向校准、薪资判断和风险提示。
4. 不输出完整岗位投递清单。
5. 不承诺岗位有效。
6. 不把岗位样本写成学生可获得机会。

给顾问的提示：

```text
你可以先在 BOSS / 猎聘 / 智联 / 前程无忧里按目标城市和方向各找 3-5 条样本，不需要大量收集。

请尽量复制岗位名称、城市、薪资区间、经验要求、学历要求、核心职责、核心要求，以及是否有销售 / KPI / 业绩属性。

我会用这些样本判断方向是否大致成立、薪资目标是否需要调整、哪些说法能对客户讲、哪些必须等渠道确认。
```

## 9. 无法联网时的输出

如果 Codex 当前无法联网，输出：

1. 建议搜索关键词。
2. 建议搜索平台。
3. 人工岗位样本收集模板。
4. 哪些结论只能标注为「样本不足 / 需后续校准」。

示例：

```text
当前无法直接联网校准。建议先人工收集 3-5 条上海「日语客户成功 / 客户运营」样本，以及 3-5 条「HR SSC / 招聘协调」样本。重点看薪资区间、是否应届友好、是否有 KPI、是否硬性要求 N1/N2。当前关于薪资可行性和岗位接受度的判断，只能标注为「样本不足 / 需后续校准」。
```

## 11. 海外规则复核联动

出现以下情况时，轻量市场校准结论必须同时标注 Rules Review 状态：

1. 澳洲 485、毕业后工作窗口、full working rights、职业路径相关判断。
2. 美国 CPT / OPT / STEM OPT / sponsor / H-1B 相关判断。
3. 香港 IANG、高才、香港身份、临时身份证、可全职工作相关判断。
4. 岗位样本明确写 no sponsorship、full working rights 或 local candidates only。

输出方式：

```text
规则复核状态：
- 不涉及 / 已基于公开信息初步校准 / 待官方规则校准 / 待专业意见确认

边界声明：
本次校准只用于求职窗口和雇主接受度判断，不构成签证、移民或法律建议。
```
