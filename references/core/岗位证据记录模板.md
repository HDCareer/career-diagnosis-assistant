# SkillⅠ v3.0｜岗位证据记录模板

## 使用目标

本文件只用于用户显式调用的「轻量市场校准」和岗位样本记录，属于未来可选增强能力，不是 SkillⅠ v3.0 默认运行流程，也不是 正式诊断报告的必做材料。

默认模式不读取、不调用本文件，不要求收集岗位样本，不要求 A/B/C/D 证据分级，不要求岗位去重，不输出岗位投递计划。

本文件不影响正式报告是否可以生成，SkillⅠ 不应在默认报告中自动建议收集岗位样本。

只有用户明确提出以下类似指令时，才启用本文件：

1. 启动市场校准。
2. 用岗位样本校准。
3. 分析这几条 JD。
4. 使用《岗位证据记录模板》。
5. 整理人工岗位样本。

## 1. 人工岗位样本收集表

每个需要校准的方向，建议收集 3-5 条样本即可。

| 编号 | 公司名称 | 岗位名称 | 城市 | 薪资区间 | 经验要求 | 学历要求 | 语言 / 技能 / 证书 | 核心职责 | 核心要求 | 销售 / KPI / 业绩属性 | 是否应届友好 | 顾问备注 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| SAMPLE-001 |  |  |  |  |  |  |  |  |  | 无 / 轻 / 明显 / 不确定 | 是 / 否 / 不确定 |  |

填写规则：

1. 薪资只记录页面公开信息，不自行估算。
2. 经验要求和是否应届友好必须分开写。
3. 如果岗位有绩效、提成、销售、KPI、续约、转化等属性，必须记录。
4. 样本只能用于方向校准，不代表岗位有效，也不代表学生可获得机会。
5. 客户版不展示完整样本表。

## 1.1 海外岗位样本补充字段

当校准香港、澳洲、美国本地求职方向时，每条样本尽量补充以下字段：

| 字段 | 内容 |
|---|---|
| 地区路径 | 香港 / 澳洲 / 美国 |
| 招聘口径 | Graduate / Entry-level / Internship / Contract / 普通社招 / Rolling Recruitment |
| 是否接受 international students | 是 / 否 / 未说明 |
| 是否要求 full working rights | 是 / 否 / 未说明 |
| 是否明确 no sponsorship | 是 / 否 / 未说明 |
| 是否提及 visa / work authorization | 原文摘录或摘要 |
| 是否要求本地经验 | 是 / 否 / 未说明 |
| 是否要求粤语 / 英语 / 普通话 |  |
| 薪资币种 | HKD / AUD / USD / RMB / 未说明 |
| 规则复核状态 | 不涉及 / 待官方规则校准 / 待专业意见确认 |

记录规则：

1. 不自行推断学生一定符合工作权利要求。
2. 不把 no sponsorship 写成学生完全没有机会，只能作为雇主接受度限制。
3. 不把 full working rights 写成身份结论，只能标注待规则复核。
4. 客户版只展示方向级结论，不展示完整岗位样本。

## 3. 检索失败或无法联网记录

| 编号 | 来源 / 平台 | 搜索关键词 | 失败原因 | 替代方案 | 暂时待校准结论 |
|---|---|---|---|---|---|
| FAIL-001 |  |  | 登录 / 验证码 / 无法联网 / 页面不可用 / 其他 | 人工样本投喂 / 换公开来源 / 等待顾问补样本 |  |

失败处理规则：

1. 失败时不要编造岗位。
2. 输出人工搜索关键词。
3. 输出人工样本收集模板。
4. 暂时只能标注「待市场校准」。

## 4. 客户版方向级摘要

客户版只能输出方向级结论。

```text
从当前公开信息和少量市场样本看，{{方向}} 在 {{城市}} 存在一定机会，但通常要求 {{能力要求}}。学生目前具备 {{匹配点}}，仍需补强 {{差距点}}。该判断仅用于方向参考，不代表具体岗位长期有效，也不代表学生已获得投递、面试或录用机会。
```

客户版不输出：

1. 大段链接。
2. 完整岗位清单。
3. 具体投递计划。
4. 岗位一定有效的表达。
5. 学生一定能投或一定有机会的表达。

## 6. 知识库分层

市场校准和 Deep Research 结果必须分层：

| 分层 | 处理方式 |
|---|---|
| 已人工确认，可进入正式知识库 | 经顾问或渠道确认后沉淀 |
| 待核查，只能暂存 | 不能直接进入正式知识库 |
| 不建议沉淀 | 来源不清、样本不足、明显过期、与业务无关 |

不得进入正式知识库的内容：

1. 未经人工确认的岗位。
2. 未经人工确认的薪资。
3. 未经人工确认的渠道反馈。
4. 未经人工确认的成功案例。
5. 未经人工确认的行业趋势。
6. 未经人工确认的竞品说法。
7. 来源不明或不可追溯的信息。

## 7. 海外样本客户版摘要

客户版只能输出方向级摘要，不得输出岗位清单。

```text
从当前公开样本看，{{地区}} 的 {{方向}} 方向存在一定公开机会，但部分岗位会关注 full working rights、local experience、语言能力或 sponsorship 限制。学生当前具备 {{匹配点}}，仍需进一步确认 {{待确认点}}。该判断仅用于求职窗口和雇主接受度参考，不代表具体岗位有效，也不代表学生一定能投递、面试或录用。
```

如果检索失败或样本不足，客户版使用：

```text
在本次检索范围、关键词、平台和时间点下，暂未获得足够公开岗位样本。该方向不能因此直接判定为没有机会，但当前不建议把薪资、岗位数量或承接可行性讲成强结论，建议后续通过人工样本或渠道进一步确认。
```
