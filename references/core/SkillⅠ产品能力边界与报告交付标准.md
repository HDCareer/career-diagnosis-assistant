# SkillⅠ产品能力边界与报告交付标准

## 1. 产品定位

SkillⅠ 本诊断服务完整交付“诊断、校准、决策和启动方案”，不是只交付会前问题清单，也不是通过故意留白保护顾问价值。

报告必须在当前材料和已确认咨询内容范围内，把客户最关心的问题尽量回答清楚；不能把已经完成咨询后能够回答的问题，再简单推回“后续咨询顾问”。

## 2. 分阶段职责

### 会前诊断初版

负责形成当前信息下的初步判断、方向假设、差距识别和 1v1 咨询议题。

会前报告可以标注“初步判断”“咨询中需要确认”，但必须说明为什么需要确认、确认后会影响什么，不得用空泛留白代替诊断。

### 顾问咨询

顾问负责事实核实、非标判断、取舍排序和对客户真实限制的校准。

顾问确认纪要、顾问总结和客户表示“可以由导师佐证”，都不能自动升级为“经历已核实真实性”或“已验证”。只有材料已提供并可追溯时，才能写成材料层面的支持；只有存在独立来源时，才能写成独立验证。

### 咨询后最终报告

最终报告负责沉淀已确认结论，逐项回答最多 3 个客户核心问题，并把方向、薪资现实性、关键差距和优先行动落到可执行层面。

最终报告重点深挖最多 3 个核心问题、最多 3 个高优先级修复卡和最多 3 个高难度行动脚手架，不为了凑数扩展。

### 后续陪跑

后续陪跑负责执行、批改、反馈和迭代，例如简历逐句修改、作品集细化、模拟面试、投递反馈复盘和材料版本管理。

这些属于执行支持，不是最终报告故意缺失诊断结论的理由。

## 3. 市场与招聘信息边界

SkillⅠ 正常 Case 不依赖实时招聘网站，不自动搜索 BOSS、LinkedIn 或其他招聘平台，不生成岗位爬虫、实时 HC、企业名单或逐 Case 实时薪资采样。

报告不得伪造市场薪资、招聘批次、岗位开放状态或来源。没有外部市场样本时，可以给出顾问对客户薪资目标的定性现实判断，但必须明确未使用外部市场参考，不得把客户期待写成市场区间。

现有《岗位搜索策略模板》只在用户显式要求、或人工提供 3—5 条岗位样本时作为可选增强能力；它不是正常 Case 的生成门槛。

## 4. 表达原则

高优先级差距遵守：

> 重构表达，不重构事实；提升叙事，不制造经历。

报告可以帮助客户把已有事实讲清楚、把证据链整理出来、把未来补强路径拆细，但不得鼓励虚构、隐瞒、伪造结果、把计划事项写成已有能力，或把尚未入学、计划考证、计划实习、计划作品写成当前竞争力资产。

## 5. 正常 Case 最小读取摘要

正常 Case 只需读取本文件摘要：

1. 完整交付诊断、校准、决策和启动方案。
2. 最终报告逐项回答最多 3 个核心问题。
3. 顾问确认不等于经历真实性已验证。
4. 当前资产、未来潜力和计划事项必须分开。
5. 无外部市场样本时不生成市场薪资数字。
6. 最多深挖 3 个修复卡和 3 个行动脚手架。
7. 不通过故意留白保护顾问价值。
8. 不依赖实时招聘网站，不伪造市场或招聘信息。

完整规格只在修改 Skill、Renderer、内容契约或发版验收时读取。

## 6. 最终报告验收标准

最终报告至少满足：

1. 逐项回答最多 3 个客户核心问题。
2. 明确主攻、备选和必要的暂缓方向。
3. 区分客户期待、顾问判断和可选外部市场参考。
4. 最多 3 个高优先级问题有具体修复方案。
5. 最多 3 个高难度行动有启动脚手架。
6. 当前能力、未来潜力和计划事项分开。
7. 自述、顾问判断和已核验证据分开。
8. 不伪造市场、薪资、岗位或录用结果。

## 7. Skill 更新与冻结机制

必须修改：原则性逻辑、事实或证据错误、承诺范围内的必要内容缺失、流程阻塞、隐私泄漏、重复出现的系统问题。

进入观察池：单 Case 措辞、轻微视觉问题、个别客户希望更丰富、可由顾问处理的非标需求。

不修改 Skill：完整简历代写、实时岗位清单、代做作品、持续陪跑、录用或薪资保证等超范围需求。
